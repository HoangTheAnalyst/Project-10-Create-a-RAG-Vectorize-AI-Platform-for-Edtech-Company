# 📖 Data Dictionary - RAG & Telemetry Analytics (Snowflake Data Marts)

This document provides a comprehensive reference for the gold layer dimensional models and fact tables transformed by dbt, capturing metadata constraints, tests, and business logic.

---

## 1. Schema: `marts` (Academic Domain & Vector Knowledge Base)

### 📂 Model: `dim_lesson`
* **Description**: Dimension table for lessons. Stores lesson-level metadata and classifications, deduplicated to the latest ingestion date.
* **Materialization**: `table`
* **Primary Key**: `lesson_sk`

| Column Name | Constraints / Tests | Description |
| :--- | :--- | :--- |
| `lesson_sk` | `not_null`, `unique` | Surrogate key for the lesson, generated via `MD5(CONCAT_WS('\|\|', subject, lesson_name))`. |
| `subject` | `not_null`, `accepted_values: ['History', 'Literature', 'Geography']` | Academic subject category to which the lesson belongs. |
| `lesson_name` | `not_null` | Descriptive name of the lesson. |

---

### 📂 Model: `fct_chunks`
* **Description**: Fact table for ingested chunks with vector representation. Stores tokenized document content along with 1024-dimensional embeddings for RAG retrieval.
* **Materialization**: `incremental` (`strategy='merge'`, `unique_key='chunk_sk'`)
* **Primary Key**: `chunk_sk`
* **Foreign Key**: `lesson_sk` (references `dim_lesson`)

| Column Name | Constraints / Tests | Description |
| :--- | :--- | :--- |
| `chunk_sk` | `not_null`, `unique` | Surrogate key for the chunk, generated via `MD5(chunk_id)`. |
| `content_type` | `not_null`, `accepted_values: ['theory', 'exercise']` | Categorical type of the ingested content. |
| `subject` | `not_null`, `accepted_values: ['History', 'Literature', 'Geography']` | Academic subject category of the chunk content. |
| `lesson_sk` | `not_null` | Surrogate key for the lesson linking to `dim_lesson`. |
| `section_title` | `not_null` | Section or heading title from the source document. |
| `chunk_type` | Attribute | Sub-type classification of the chunk (e.g., lecture theory, question, answer). |
| `content` | `not_null` | Main text payload to be vectorized and supplied as LLM context. |
| `chunk_vector` | `not_null` | Vector representation of the chunk content. |
| `ingested_at` | `not_null` | Timestamp when the chunk was ingested into the fact table. |

## 2. Schema: `marts_log` (Telemetry & Observability Analytics)

### 📂 Model: `fct_log`
* **Description**: Fact table recording all AI assistant query logs, performance metrics, and retrieval evaluations. PII fields are anonymized via MD5 hashing.
* **Materialization**: `incremental` (`strategy='append'`)
* **Primary Key**: `query_sk`
* **Foreign Key**: `lesson_sk` (references `dim_lesson`)
* **Model-level Test**: `check_top_similarity_score_valid_range`: `(top_similarity_score >= similarity_threshold AND top_similarity_score <= 1.0) OR (chunks_retrieved = 0 AND top_similarity_score = 0.0)`

| Column Name | Constraints / Tests | Description |
| :--- | :--- | :--- |
| `query_sk` | `not_null`, `unique` | Surrogate key generated from `query_id` (Primary Key). |
| `hashed_client_ip` | `not_null` | Hashed client IP address for user tracking and privacy compliance. |
| `session_sk` | `not_null` | Surrogate key generated from `session_id` for session-level analysis. |
| `conversation_sk` | `not_null` | Surrogate key generated from `conversation_id` for thread-level analysis. |
| `lesson_sk` | `not_null` | Foreign surrogate key linking to `dim_lesson`. |
| `selected_subject` | `not_null` | Subject selected by the user in the interface. |
| `selected_lesson` | `not_null` | Lesson selected by the user in the interface. |
| `similarity_threshold` | `not_null`, range: `[0, 1]` | Minimum similarity threshold configured for vector retrieval. |
| `chunks_retrieved` | `not_null`, `>= 0` | Total number of context chunks retrieved from vector search. |
| `top_similarity_score` | `not_null`, range: `[0, 1]` | Highest cosine similarity score among the retrieved chunks. |
| `latency_seconds` | `not_null`, `>= 0` | End-to-end processing time for query in seconds. |
| `user_query_length` | `not_null`, `>= 0` | Character count of the user's prompt. |
| `ai_response_length` | `not_null`, `>= 0` | Character count of the response generated by AI. |
| `similarity_score_diff` | `not_null` | Margin between the highest similarity score and the threshold (`top_score - threshold`). |
| `no_chunks_retrieved` | `not_null` | Boolean flag indicating whether zero chunks met the retrieval threshold (`chunks_retrieved = 0`). |
| `high_latency` | `not_null` | Boolean flag indicating if total latency exceeded 5 seconds SLA (`latency_seconds > 5`). |
| `created_at` | `not_null` | Timestamp when the query was logged. |

---

### 📂 Model: `fct_answer`
* **Description**: Fact table containing answer-related metrics. Confidential/restricted access mart preserving raw student queries (`user_query`) and unmasked AI responses (`ai_response`) for deep-dive quality audits.
* **Materialization**: `table`
* **Primary Key**: `query_sk`
* **Foreign Key**: `query_sk` (references `fct_log`)

| Column Name | Constraints / Tests | Description |
| :--- | :--- | :--- |
| `query_sk` | `not_null`, `unique` | Surrogate key linking to `fct_log`. |
| `session_id` | `not_null` | Identifier for the user session. |
| `conversation_id` | `not_null` | Identifier for the conversation thread. |
| `conversation_name` | `not_null` | Name of the conversation thread. |
| `selected_subject` | `not_null`, `accepted_values: ['All', 'History', 'Literature', 'Geography']` | The subject selected by the user for the query. |
| `selected_lesson` | `not_null` | The lesson selected by the user for the query. |
| `user_query` | `not_null` | The original query submitted by the user. |
| `ai_response` | `not_null` | The response generated by the AI model. |
| `created_at` | `not_null` | Timestamp when the answer was logged. |
